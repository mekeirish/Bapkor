À propos d'APKor
📦
Mode Projet
Choisis un dépôt GitHub existant. Le build utilise son index.html et ses ressources.
✏️
Mode Code direct
Colle ton code HTML → il sera poussé dans le sandbox testapk puis compilé.
🖼️
Icône personnalisée
Image convertie automatiquement en PNG carré 1024×1024 et poussée dans le dépôt.
🔐
Permissions auto
Le workflow détecte automatiquement vibration, notifications, caméra, micro, géoloc et injecte les permissions Android nécessaires.
📱
QR Code
Scanne le QR pour télécharger l'APK directement sur ton téléphone.
